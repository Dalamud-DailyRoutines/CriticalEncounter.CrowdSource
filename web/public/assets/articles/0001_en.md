# How to Get the Instance ID

## Daily Routines

> [!NOTE]
> This method requires the Dalamud framework and installation of third-party plugins

1. In Dalamud, add [AtmoOmen's Dalamud plugin repository](https://github.com/AtmoOmen/DalamudPlugins) as a third-party repository and save.
2. Search for and install the `Daily Routines` plugin in the plugin installer.
3. Enable the module `Explicit Instance ID For Field Operations` in the plugin.

Once enabled, when entering Field Operation duties, the server info bar displays the current instance ID, and a chat message containing the current instance ID is sent.

## InstanceFinder

> [!NOTE]
> This method is standalone Windows software and may not run on Windows 10 or earlier

A standalone console tool that requires no framework:

- [Download InstanceFinder.exe](/assets/InstanceFinder.exe)

Operation steps:

1. Choose the UI language.
2. Choose the FINAL FANTASY XIV game instance to read (this step is skipped automatically when only one process is available).
3. The program automatically reads and outputs the current instance ID. Press any key to read and output again; press Ctrl+C twice in succession to exit.

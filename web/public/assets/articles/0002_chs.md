# 外部调用指引

通过 HTTP 订阅指定区域，再读取返回的 JSON 地址，可以获取区域内各事件最近一次已观测发生时间。接口支持浏览器跨域访问，所有时间戳均为 UTC Unix 秒。

## 订阅区域

向 `https://ce-crowdsource.atmoomen.top/v1/subscriptions` 发送 `POST` 请求，使用 `Content-Type: application/json`。将示例中的 `instanceID` 替换为页面正在显示的实例 ID。

```json
{
  "dataCenterID": 101,
  "instances": [
    { "instanceID": 123456, "territoryID": 1252 }
  ]
}
```

`dataCenterID` 可从页面地址的 `/dc/` 后读取，`instanceID` 与页面中的实例 ID 对应。区域 ID 使用[事件目录](/assets/dynamic-event-catalog.json)中区域的 `territoryID`；该字段和用于地图展示的 `mapID` 各有用途。每次请求支持同一 DC 的 1～32 个实例与区域组合。

```json
{
  "dataCenterID": 101,
  "serverTime": 1788825600,
  "subscriptions": [
    {
      "instanceID": 123456,
      "territoryID": 1252,
      "snapshotURL": "https://ce-data.atmoomen.top/v1/events/101/123456/1252.json.js?revision=9efbf972-a6e2-4014-af55-cbe1dd318554",
      "revision": "9efbf972-a6e2-4014-af55-cbe1dd318554",
      "expiresAt": 1788827400,
      "renewAfter": 1788826500
    }
  ]
}
```

订阅有效期为 30 分钟，到达 `renewAfter` 后使用相同请求续订。多个调用方共享同一区域的发布有效期，提前重复调用沿用当前有效期。停止续订后，该区域在有效期结束时暂停更新；再次订阅会准备最新数据。

## 读取事件记录

向响应提供的 `snapshotURL` 发送 `GET` 请求，建议每 30 秒读取一次，并复用完整地址。事件变化后快照会更新，CDN 缓存有效期为 30 秒。`revision` 是用于判断内容变化的版本标识，`updatedAt` 表示快照内容更新时间。

```json
{
  "schemaVersion": 1,
  "dataCenterID": 101,
  "instanceID": 123456,
  "territoryID": 1252,
  "instanceEpoch": 1,
  "tracks": [
    {
      "trackID": "SouthHorn-1",
      "events": [
        { "eventType": "CE", "eventID": 33, "lastSpawnedAt": 1788825500 },
        { "eventType": "CE", "eventID": 34, "lastSpawnedAt": null }
      ]
    }
  ],
  "revision": "9efbf972-a6e2-4014-af55-cbe1dd318554",
  "updatedAt": 1788825600
}
```

示例节选了部分事件，实际 `events` 包含该区域目录中的全部事件。`eventType` 为 `CE` 或 `FATE`，`lastSpawnedAt: null` 表示该轨迹尚待观测到对应事件。事件名称、图标等静态资料可通过 `eventType` 和 `eventID` 关联事件目录。

实例 ID 回收复用时，`tracks` 可能包含多个候选实例轨迹，其分组与页面一致；使用 `trackID` 分别展示或选择各组记录。空 `tracks` 表示当前区域的记录已清理，或该实例在此区域尚待上报。`instanceEpoch` 表示服务端识别的实例代次。

快照记录每个事件最近一次已观测发生时间。新的发生记录、实例轨迹变化和记录清理会更新内容，阶段变化及重复报告沿用已有快照。实例状态按 24 小时接收记录保留窗口清理；到期后的旧读取地址仍可能返回保留的 JSON，使用数据时应同时遵守订阅响应中的 `expiresAt`。

## JavaScript 示例

以下函数在需要续订时更新有效期，然后读取区域数据，可从应用的刷新任务中每 30 秒调用一次。示例使用本机时间判断续订，应用可结合响应中的 `serverTime` 校准时间。

浏览器请求使用 `cache: "no-cache"` 重新验证本地缓存；路径以 `.json.js` 结尾，响应内容类型为 `application/json`。

```javascript
const target = {
  dataCenterID: 101,
  instances: [{ instanceID: 123456, territoryID: 1252 }]
};
let subscription;

async function readEvents() {
  if (!subscription || Date.now() / 1000 >= subscription.renewAfter) {
    const response = await fetch("https://ce-crowdsource.atmoomen.top/v1/subscriptions", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(target)
    });
    if (!response.ok) throw new Error(await response.text());
    subscription = (await response.json()).subscriptions[0];
  }

  const response = await fetch(subscription.snapshotURL, { cache: "no-cache" });
  if (!response.ok) throw new Error(await response.text());
  return response.json();
}
```

## 请求限制与错误处理

订阅接口按来源 IP 在边缘限制每分钟 10 次请求，每个 DC 最多同时启用 64 个区域。持续读取使用 `snapshotURL`，订阅请求可合并同一 DC 的多个区域。批量请求中的实例应为页面近期观测到的实例。

| HTTP 状态 | 处理方式 |
| --- | --- |
| `400` | 检查 DC、实例与区域参数、重复组合和 JSON 格式。 |
| `404` | 指定实例的近期记录尚待上报，请确认实例 ID 后稍后重试。 |
| `413` | 请求体超过 4 KiB，请缩小批次。 |
| `429` | 按响应的 `Retry-After` 等待后重试。 |
| `503` | 快照准备或服务暂时失败，按 `Retry-After` 等待后重试。 |

发生错误时使用退避重试，并在订阅到期后重新建立有效订阅再使用数据。浏览器调用采用公开接口，上传观察报告所使用的凭证由报告客户端独立管理。

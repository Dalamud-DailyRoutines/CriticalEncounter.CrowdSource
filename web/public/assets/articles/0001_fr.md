# Obtenir l'ID d'instance

## Daily Routines

> [!NOTE]
> Cette méthode nécessite le framework Dalamud et l'installation d'un plugin tiers

1. Dans Dalamud, ajouter le [dépôt de plugins Dalamud d'AtmoOmen](https://github.com/AtmoOmen/DalamudPlugins) comme dépôt tiers et enregistrer.
2. Rechercher et installer le plugin `Daily Routines` dans l'installeur de plugins.
3. Activer le module `Explicit Instance ID For Field Operations` dans le plugin.

Une fois activé, à l'entrée dans les opérations de terrain concernées, l'ID d'instance courant s'affiche dans la barre d'informations du serveur et un message de chat contenant l'ID d'instance courant est envoyé.

## InstanceFinder

> [!NOTE]
> Cette méthode est un logiciel Windows autonome qui peut ne pas fonctionner sous Windows 10 et versions antérieures

Un outil console autonome sans dépendance à un framework :

- [Télécharger InstanceFinder.exe](/assets/InstanceFinder.exe)

Procédure :

1. Choisir la langue de l'interface.
2. Choisir l'instance de jeu FINAL FANTASY XIV à lire (cette étape est automatiquement ignorée si un seul processus est disponible).
3. Le programme lit et affiche automatiquement l'ID d'instance courant. Appuyer sur une touche pour relire et réafficher ; appuyer deux fois de suite sur Ctrl+C pour quitter.

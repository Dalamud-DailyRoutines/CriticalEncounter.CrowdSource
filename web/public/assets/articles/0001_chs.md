# 如何获取副本实例 ID？

## Daily Routines

> [!NOTE]
> 本方法需要 Dalamud 框架与安装第三方插件

1. 在 Dalamud 内, 添加 [AtmoOmen 的 Dalamud 插件库](https://github.com/AtmoOmen/DalamudPlugins) 为第三方仓库并保存。
2. 在插件安装器内搜索并安装 `Daily Routines` 插件。
3. 在插件内启用模块 `自动显示特殊场景探索副本 ID`。

启用后, 在进入特殊场景探索相关副本时, 服务器信息栏将显示当前副本实例 ID, 聊天栏内也会发送包含当前副本实例 ID 的消息。

## InstanceFinder

> [!NOTE]
> 本方法为独立 Windows 软件, 可能无法在 Windows 10 及以下版本运行

不依赖任何框架的独立控制台工具：

- [下载 InstanceFinder.exe](/assets/InstanceFinder.exe)

操作流程:

1. 选择界面语言。
2. 选择想要读取的《最终幻想XIV》游戏实例（在仅有一个可用进程时会自动跳过本步）。
3. 程序将自动读取并输出当前副本实例 ID, 按下任意键可再次读取并输出, 连续按下两次 Ctrl+C 即可退出进程。

# 인스턴스 ID 확인 방법

## Daily Routines

> [!NOTE]
> 이 방법은 Dalamud 프레임워크와 서드파티 플러그인 설치가 필요합니다

1. Dalamud에서 [AtmoOmen의 Dalamud 플러그인 저장소](https://github.com/AtmoOmen/DalamudPlugins)를 서드파티 저장소로 추가하고 저장합니다.
2. 플러그인 설치 창에서 `Daily Routines` 플러그인을 검색해 설치합니다.
3. 플러그인에서 `특수 필드 탐색 인스턴스 ID 자동 표시` 모듈을 활성화합니다.

활성화하면 특수 필드 탐색 관련 던전에 진입할 때 서버 정보 표시줄에 현재 인스턴스 ID가 표시되고, 현재 인스턴스 ID가 포함된 채팅 메시지도 전송됩니다.

## InstanceFinder

> [!NOTE]
> 이 방법은 독립 실행형 Windows 소프트웨어로, Windows 10 이하에서는 실행되지 않을 수 있습니다

프레임워크가 필요 없는 독립 실행형 콘솔 도구입니다:

- [InstanceFinder.exe 다운로드](/assets/InstanceFinder.exe)

작동 순서:

1. 표시 언어를 선택합니다.
2. 읽을 파이널 판타지 XIV 게임 인스턴스를 선택합니다 (사용 가능한 프로세스가 하나뿐이면 자동으로 건너뜁니다).
3. 프로그램이 현재 인스턴스 ID를 자동으로 읽어 출력합니다. 아무 키나 누르면 다시 읽어 출력하며, Ctrl+C를 연속으로 두 번 누르면 종료됩니다.

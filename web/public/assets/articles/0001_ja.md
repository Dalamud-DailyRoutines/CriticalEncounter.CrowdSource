# インスタンス ID の取得方法

## Daily Routines

> [!NOTE]
> この方法には Dalamud フレームワークとサードパーティプラグインのインストールが必要です

1. Dalamud 内で [AtmoOmen の Dalamud プラグインリポジトリ](https://github.com/AtmoOmen/DalamudPlugins) をサードパーティリポジトリとして追加して保存します。
2. プラグインインストーラーで `Daily Routines` プラグインを検索してインストールします。
3. プラグイン内でモジュール `特殊フィールド探索の島IDを表示` を有効にします。

有効にすると、特殊フィールド探索関連のコンテンツに突入した際、サーバー情報に現在のインスタンス ID が表示され、現在のインスタンス ID を含むチャットメッセージも送信されます。

## InstanceFinder

> [!NOTE]
> この方法はスタンドアロンの Windows ソフトウェアで、Windows 10 以前では動作しない可能性があります

フレームワーク不要のスタンドアロンコンソールツールです:

- [InstanceFinder.exe をダウンロード](/assets/InstanceFinder.exe)

操作手順:

1. 表示言語を選択します。
2. 読み取り対象の『ファイナルファンタジーXIV』ゲームインスタンスを選択します（利用可能なプロセスが 1 つのみの場合は自動的にスキップされます）。
3. プログラムが現在のインスタンス ID を自動的に読み取って出力します。任意のキーで再読み取り・出力し、Ctrl+C を 2 回続けて押すと終了します。
